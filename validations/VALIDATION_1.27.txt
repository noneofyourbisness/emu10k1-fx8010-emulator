New source-backed behavior
--------------------------
Creative US 6,032,235 initialization controller promoted to an executable
reference model:
- READ CLR returns zero while global zeroedSamples < programmed delay length.
- READ becomes valid exactly at equality.
- internal RSAW CLR forces zero write while countdown is active.
- microcode data-buffer writes are blocked for a clearing RSAW slot.
- global zeroedSamples counter saturates rather than wrapping.

Scope discipline
----------------
Recovered public RIFX records do not serialize the CLR/countdown metadata, so
this controller is not silently enabled for ordinary factory RIFX playback.
RSAW overflow law, external-XTRAM RSAW, XTRAM last-FIFO-slot pair priority,
late-service payload behavior, exact PCI completion latency, LOCKTANKCACHE
resident-cache contents, and exact NOISE silicon behavior remain explicitly
unresolved.
